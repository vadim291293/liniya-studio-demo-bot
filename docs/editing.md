# Как заказчик редактирует бота

Изменения в активном сценарии могут повлиять на следующие запуски. Перед значительной переработкой сохраните копию сценария средствами платформы и проверьте её отдельно.

| Что изменить | Где искать |
| --- | --- |
| Приветствие и главное меню | Шаг «01 Приветствие» |
| Вопросы анкеты и варианты ответов | Карточки «Вопрос» в «02 Заявка» |
| Сохранение ответов | Поле подписчика, выбранное в карточке вопроса |
| Описания услуг и FAQ | «03 Услуги и вопросы» |
| Приглашение к консультации | «05 Начало консультации» |
| Правила ответа ИИ | AI-агент → инструкция |
| Сведения о студии | AI-агент → текстовая база знаний |
| Переход кнопки | Настройки кнопки → целевой шаг |
| Возврат в меню | Отдельная автоматизация `/menu` и `меню` |

Для редактирования шага откройте его в визуальном редакторе, внесите изменения и сохраните. Затем пройдите изменённую ветку в Telegram с вымышленными данными.

Для демонстрации заказчику достаточно изменить одну фразу FAQ, сохранить и показать новый текст в Telegram. После демонстрации верните исходное значение.

Не публикуйте в базе знаний секреты или сведения, которые не должны быть доступны пользователям бота. Указание темы в инструкции ИИ не заменяет проверку его ответов.
