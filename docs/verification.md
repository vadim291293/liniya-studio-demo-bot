# Проверка бота

## Подтверждённое состояние

- 13 октября 2026 года: сценарий создан и активирован; в карточке подписчика подтверждено сохранение шести ответов анкеты.
- 13 октября: обнаружен преждевременный запуск приветствия из функции AI-агента. Функция выключена, инструкция обновлена; сохранение проверено повторным открытием настроек.
- 14 октября: владелец сообщил, что бот работает после исправлений.

Это демонстрационный проект. Полная независимая проверка всех сочетаний команд, старых кнопок и ошибок платформы не заявляется.

## Сценарии для ручной проверки

| Проверка | Ожидаемый результат |
| --- | --- |
| Отправить `/start` | Приветствие и три кнопки |
| Выбрать «Услуги и вопросы» | Описания форматов и FAQ |
| Вернуться кнопкой в меню | Настоящие кнопки меню, а не их текстовая имитация |
| Заполнить все шесть вопросов | Подтверждение; ответы видны в карточке подписчика |
| Отправить `/menu` посреди анкеты | Текущее прохождение остановлено, открыто приветствие |
| Войти в ИИ | Приглашение написать вопрос; нет преждевременного вызова главного меню |
| Спросить про лендинг и сайт компании | Содержательное объяснение на русском языке |
| Спросить точную цену и срок | Сообщение, что фиксированные условия в демо не заданы |
| Отправить `/menu` из ИИ | Приветствие с кнопками |
| Повторить вход в анкету и ИИ | Обе ветки снова доступны |
| Не отвечать ИИ более двух минут | Завершение ожидания и переход к приветствию |

Для проверки используйте «Тестовый клиент» и «тестовый контакт». Скриншоты карточек реальных пользователей и переписки не входят в репозиторий.
